# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this folder.

KBO 11번째 구단 창단 웹 앱이다. `KBO11번째구단_실행.bat`을 더블클릭하면 같은 폴더의 `index.html`(`%~dp0`)을 기본 브라우저로 연다(CRLF, `chcp 65001`). 순수 HTML/CSS/JS 파일 하나(`index.html`)이고 서버나 외부 API가 필요 없다. 브라우저로 열면 바로 동작하고, 진행 상황은 `sessionStorage`의 `kbo11-v3` 키에 저장돼 같은 탭에서 새로고침할 때만 이어지고, 새로 실행하면 항상 첫 화면부터 시작한다(사용자 요청).

## 흐름 (`go(step)`)

1. 창단: 구단주 이름, 연고지(칩 또는 직접 입력), 팀명, 상징색. 기본 테마는 은은한 남색 `#4A5B8C`이고, 색을 고르면 `applyTheme()`가 `--primary`를 상징색으로 바꾼다(밝은 색이면 글자색을 어둡게).
2. 선수 영입: `SLOTS`(선발 4, 불펜 7, 1B·2B·3B·SS 각 2, 외야 6, 포수 2, 지명타자 1 = 28명). 지명타자 칸은 투수가 아닌 모든 선수에서 고른다. 외국인 3명 제한, 앱 연봉 합계가 구단 자금 120억(`CAP`)을 넘을 수 없다. 28명을 다 뽑으면 화면을 흐리게 하고 '라인업 짜기'/'선수 다시 선택하기' 창(`showDone()`)을 띄운다.
3. 라인업: 선발투수 1명 + 1~9번. 수비 위치는 선수 포지션(외야수는 좌·중·우), 겸하는 포지션, 지명타자 중 하나이고 위치마다 한 명. 다른 줄에서 이미 채운 수비 위치의 선수는 타자 목록에서 숨긴다(남은 자리가 지명타자뿐이거나 그 줄이 지명타자면 다 보여 줌). 줄마다 삭제 버튼. 오른쪽 픽셀 야구장(`renderField()`, 82×80 SVG)에 선수가 들어간 위치마다 깜빡이는 빨간 픽셀 점과 이름을 그린다. 나머지는 공식 등록 포지션(투수/내야수/외야수/포수)으로 나눠 후보로 보여 준다.
4. 출범: 상징색 배경, 픽셀 선수들이 점프, 캔버스 종이가루, "2027년 프로야구 11번째 구단 출범".

화면에 보이는 글에는 "KBO" 대신 "프로야구"를 쓰고(사용자 요청), 맨 아래와 출범 화면에 작게 "실제 리그·구단과 무관한 팬 제작 게임이에요"(`.disclaimer`)를 넣는다.

## 데이터

- 모두 KBO 공식 사이트(koreabaseball.com) 기준이다. 사용자가 포지션 등을 임의로 바꾸지 말고 공식 사이트에 나온 대로 하라고 했다.
- `DATA`: `[이름, 팀, 포지션, 겸하는 포지션('1B/DH'), 공식 등록 포지션, 투타, 연봉(만원), 공식 연봉 표기, 기록, 기록 연도, 외국인이면 KBO 뛴 해, 현역 아님(1), 사진 경로, 2022~2026 경기 수]`.
- 대상: 현재 10개 구단 선수 + 2022~2026 KBO 외국인 중 그 기간 1군 100경기 이상(구단·시즌별 공식 타자/투수 기록의 G 합계). 선발투수(2022~2026 경기당 3이닝 이상)는 사용자 요청으로 경기 수 제한 없이 넣는다. 은퇴·상무 등 현재 10개 구단에 없는 국내 선수는 뺀다.
- 투타·연봉·기록은 공식 선수 페이지(`Record/Player/HitterDetail|PitcherDetail/Basic.aspx?playerId=`). 선수 그림은 공식 사진이 아니라 소속 구단 색 모자·유니폼의 픽셀 캐릭터(`avatar()`)로 한다(사용자 요청). `DATA`의 사진 경로는 쓰지 않는다.
- 세부 포지션: 가장 최근 시즌 공식 수비 기록(`Record/Player/Defense/Basic.aspx`, 구단별 조회)에서 가장 많이 나간 자리, 30경기 이상 나간 다른 자리와 지명타자는 겸하는 포지션. 공식 등록 포지션(내야수/외야수)과 다르면 등록 포지션 안의 자리를 주 포지션으로 한다. 투수는 2022~2026 기록 전체에서 경기당 3이닝 이상이면 선발.
- 후보 선수 구분(투수/내야수/외야수/포수)은 공식 등록 포지션을 쓴다. 이름이 같은 선수는 `이승현(좌투)`처럼 구분한다.
- 달러 연봉은 1달러 1,400원으로 바꾼다. `appPay()`: 실제 연봉을 구간 금액(3천만/8천만/1.5억/3억/6억/15억/25억)으로 바꾼다. 8천만 미만은 모두 3천만, 25억 이상은 25억.
- 선수 번호(`id`)는 `DATA` 순서라서 데이터를 바꾸면 저장 키(`kbo11-v3`)도 올려 예전 저장분을 버린다.
- 데이터는 공식 사이트를 ASP.NET 포스트백(시즌·구단 선택, 페이지 넘김)으로 긁어서 만들었다. 다시 만들 때도 같은 방법을 쓴다.

## 확인

Node가 없으므로 headless Edge(`msedge --headless --dump-dom` / `--screenshot`)로 본다. 로직 테스트는 `index.html` 복사본의 `</body>` 앞에 상태를 채우는 스크립트를 넣어 결과를 `<pre>`로 출력한다.

## claude.ai 공유본

- 아티팩트: https://claude.ai/artifact/P9eVDfjCRtVZA4pn8rNSrp (링크가 있는 사람 누구나 볼 수 있게 공유됨, 공유 설정은 사용자가 Share 메뉴에서 한다). 아티팩트 제목은 "프로야구 11번째 구단주가 되어보자!"라서 올릴 때 첫 줄 `<title>`을 이걸로 바꾼다.
- 아티팩트는 문서 뼈대를 자동으로 씌우므로 `index.html`에서 `<!doctype>`·`<html>`·`<head>`·`<body>` 태그와 앞쪽 meta 두 줄을 뺀 복사본을 올린다. 업데이트할 때는 같은 URL(`url`)로 다시 올린다.
- 아티팩트에서는 `confirm()`/`alert()` 창이 뜨지 않으므로 쓰지 않는다(새 구단 만들기는 버튼을 두 번 누르는 방식).
- 진행 상황은 보는 사람 탭마다 따로 저장되고 새로 열면 첫 화면부터 시작한다(`sessionStorage`).
